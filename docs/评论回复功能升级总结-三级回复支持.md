```javascript
async replyToComment(accountId, options) {
    // 解析评论层级（1/2/3）
    let commentLevel = 1;
    let replyId = null;
    let replyToReplyId = null;

    if (target_comment) {
        if (target_comment.reply_to_reply_id && target_comment.reply_to_reply_id !== '0') {
            // 三级回复 ⭐
            commentLevel = 3;
            replyId = target_comment.reply_id;          // 一级根评论
            replyToReplyId = target_id;                 // 二级评论
        } else if (target_comment.reply_id && target_comment.reply_id !== '0') {
            // 二级回复
            commentLevel = 2;
            replyId = target_id;
        }
    }

    // 调用新的视频详情页回复模块
    const result = await sendReplyToCommentVideoDetail(page, {
        accountId,
        awemeId,
        replyContent: reply_content,
        commentLevel,      // ⭐ 支持1/2/3级
        replyId,           // 一级或二级ID
        replyToReplyId,    // 三级回复需要
    });
}
```

## 核心技术改进

### 三级评论层次结构

| 评论类型 | 参数要求 | API请求参数 |
|---------|---------|------------|
| **一级评论** | `aweme_id` + `text` | `reply_id`: 无<br>`reply_to_reply_id`: 无<br>`one_level_comment_rank`: -1 |
| **二级回复** | `aweme_id` + `text` + `reply_id` | `reply_id`: 一级评论cid<br>`reply_to_reply_id`: 无<br>`one_level_comment_rank`: 一级排名 |
| **三级回复** ⭐ | `aweme_id` + `text` + `reply_id` + `reply_to_reply_id` | `reply_id`: 一级根评论cid<br>`reply_to_reply_id`: 二级评论cid<br>`one_level_comment_rank`: 根评论排名 |

### API端点变更

| 版本 | API端点 | Pattern |
|-----|---------|---------|
| 创作中心（旧） | `https://creator.douyin.com/creator-micro/comment/reply` | `**/comment/reply{/,}?**` |
| 视频详情页（新）⭐ | `https://www.douyin.com/aweme/v1/web/comment/publish` | `**/aweme/v1/web/comment/publish**` |

### 响应格式差异

**创作中心（旧）**:
```json
{
  "status_code": 0,
  "comment_info": {
    "comment_id": "...",
    "content": "..."
  }
}
```

**视频详情页（新）** ⭐:
```json
{
  "status_code": 0,
  "comment": {
    "cid": "7578755020364956451",
    "status": 7,
    "text": "测试API拦截-三级回复",
    "reply_id": "7545801600418300735",        // 一级根评论
    "reply_to_reply_id": "7546608049843897130", // 二级评论
    "reply_comment": [...]  // 被回复评论的详细信息
  }
}
```

## 迁移指南

### 对于已有代码

如果你之前使用了 `send-reply-to-comment.js` 模块：

#### 1. 更新导入语句

```javascript
// 旧代码
const { sendReplyToComment } = require('./platforms/douyin/send-reply-to-comment');

// 新代码 ⭐
const { sendReplyToCommentVideoDetail } = require('./platforms/douyin/send-reply-to-comment-video-detail');
```

#### 2. 更新函数调用

**旧版本参数**:
```javascript
await sendReplyToComment(page, {
    accountId: 'xxx',
    videoTitle: '视频标题',
    replyContent: '回复内容',
    commentId: '7565319628098143022',
    commentContent: '评论内容',
    authorName: '作者名',
    level: 2,
});
```

**新版本参数** ⭐:
```javascript
await sendReplyToCommentVideoDetail(page, {
    accountId: 'xxx',
    awemeId: '7534563676188052786',  // ⚠️ 必需：视频ID
    replyContent: '回复内容',
    commentLevel: 2,                 // 1/2/3
    replyId: '7565319628098143022',  // 二级和三级需要
    replyToReplyId: null,            // 仅三级需要
});
```

#### 3. 关键差异

| 参数 | 旧版本 | 新版本 | 说明 |
|-----|--------|--------|------|
| 视频标识 | `videoTitle` | `awemeId` ⭐ | 新版本需要视频ID |
| 评论层级 | `level` | `commentLevel` | 名称变更 |
| 回复目标 | `commentId` | `replyId` + `replyToReplyId` | 三级需要两个ID |
| 匹配方式 | `commentContent` + `authorName` | 不需要 | 新版本直接用ID定位 |

## 常见问题

### Q1: 旧版本还能用吗？

A: 旧版本代码已备份到 `send-reply-to-comment-creator-center.backup.js`，如需回退可以恢复。但建议使用新版本，因为它支持三级回复。

### Q2: 如何获取 aweme_id？

A:
- 从视频URL提取: `https://www.douyin.com/video/7534563676188052786`
- 从评论通知API获取
- 从作品爬虫数据获取

### Q3: 三级回复的父子关系如何确定？

A:
```
一级评论 (cid: A)
  └─ 二级回复 (cid: B, reply_id: A)
      └─ 三级回复 (cid: C, reply_id: A, reply_to_reply_id: B)
```

### Q4: 如何调试API拦截器？

A: 查看日志输出：
```
🔍 [API拦截器-视频详情页] 捕获到评论发布请求
✅ [API] 评论发布成功: cid=xxx, level=3
```
