# 短信验证码完整处理流程实现

**文档类型**: ✅ 功能实现 - 短信验证码自动化处理
**创建时间**: 2025-12-02
**实现状态**: 100% 完成
**关联功能**: 抖音评论验证处理

---

## 概述

当用户在IM端选择"是 - 继续验证"后，系统自动完成以下流程：
1. Worker自动点击"发送验证码"按钮
2. IM端弹出输入框让用户输入短信验证码
3. Worker自动填写验证码到抖音页面
4. Worker自动点击"确认"按钮
5. 验证成功后重新发送评论

---

**函数**: `handleSMSVerification(page, requestSMSCodeCallback)`

```javascript
async function handleSMSVerification(page, requestSMSCodeCallback) {
    logger.info('📱 开始处理短信验证码流程...');

    try {
        // 1. 查找并点击"获取验证码"或"发送验证码"按钮
        const sendSMSButton = await page.evaluate(() => {
            const buttons = Array.from(document.querySelectorAll('button, div[role="button"], span'));
            for (const btn of buttons) {
                const text = btn.textContent?.trim() || '';
                if (text.includes('获取验证码') || text.includes('发送验证码') || text === '发送') {
                    return btn;
                }
            }
            return null;
        });

        if (!sendSMSButton) {
            return { success: false, message: '未找到发送验证码按钮' };
        }

        // 点击发送短信按钮
        await page.evaluate((btn) => {
            if (btn && typeof btn.click === 'function') {
                btn.click();
            }
        }, sendSMSButton);

        logger.info('✅ 已点击发送验证码按钮');
        await page.waitForTimeout(2000);

        // 2. 请求IM端用户输入验证码
        const smsCode = await requestSMSCodeCallback();

        if (!smsCode || smsCode.length === 0) {
            return { success: false, message: '用户未输入验证码' };
        }

        // 3. 查找验证码输入框并填写
        const inputFilled = await page.evaluate((code) => {
            // 方法1: 查找type="text"的输入框
            const inputs = Array.from(document.querySelectorAll('input[type="text"]'));
            for (const input of inputs) {
                const placeholder = input.placeholder || '';
                const name = input.name || '';
                if (placeholder.includes('验证码') || name.includes('code') || name.includes('captcha')) {
                    input.value = code;
                    input.dispatchEvent(new Event('input', { bubbles: true }));
                    input.dispatchEvent(new Event('change', { bubbles: true }));
                    return true;
                }
            }

            // 方法2: 查找所有input，使用最后一个
            const allInputs = Array.from(document.querySelectorAll('input'));
            if (allInputs.length > 0) {
                const lastInput = allInputs[allInputs.length - 1];
                lastInput.value = code;
                lastInput.dispatchEvent(new Event('input', { bubbles: true }));
                lastInput.dispatchEvent(new Event('change', { bubbles: true }));
                return true;
            }

            return false;
        }, smsCode);

        if (!inputFilled) {
            return { success: false, message: '未找到验证码输入框' };
        }

        logger.info('✅ 验证码已填写');
        await page.waitForTimeout(1000);

        // 4. 查找并点击"确认"或"提交"按钮
        const confirmButton = await page.evaluate(() => {
            const buttons = Array.from(document.querySelectorAll('button, div[role="button"]'));
            for (const btn of buttons) {
                const text = btn.textContent?.trim() || '';
                if (text.includes('确认') || text.includes('提交') || text === '确定' || text === 'OK') {
                    return btn;
                }
            }
            return null;
        });

        if (!confirmButton) {
            return { success: false, message: '未找到确认按钮' };
        }

        // 点击确认按钮
        await page.evaluate((btn) => {
            if (btn && typeof btn.click === 'function') {
                btn.click();
            }
        }, confirmButton);

        logger.info('✅ 已点击确认按钮');
        await page.waitForTimeout(3000);

        // 5. 检查验证是否成功
        const stillHasVerification = await page.evaluate(() => {
            const bodyText = document.body.textContent || '';
            return bodyText.includes('接收短信验证码') ||
                   bodyText.includes('为确保是本人操作抖音账号') ||
                   bodyText.includes('验证码错误') ||
                   bodyText.includes('验证失败');
        });

        if (stillHasVerification) {
            return { success: false, message: '验证失败或验证码错误' };
        }

        logger.info('✅ 短信验证成功！');
        return { success: true };

    } catch (error) {
        logger.error('❌ 短信验证处理失败', { error: error.message });
        return { success: false, message: error.message };
    }
}
```

**关键步骤**:
1. **查找发送按钮**: 支持"获取验证码"、"发送验证码"、"发送"等文本
2. **请求验证码**: 通过回调函数请求IM端输入
3. **填写验证码**: 两种方法查找输入框（优先匹配placeholder/name，fallback到最后一个input）
4. **点击确认**: 查找"确认"、"提交"、"确定"、"OK"等按钮
5. **验证结果**: 检查页面是否还有验证相关文本

```javascript
async requestSMSCode(accountId, smsCodeInfo) {
    if (!this.socket) {
      throw new Error('Socket not connected');
    }

    return new Promise((resolve, reject) => {
      const requestId = `sms_code_${accountId}_${Date.now()}`;

      try {
        // 发送验证码输入请求到 Master
        this.socket.emit('worker:sms_code:request', {
          request_id: requestId,
          account_id: accountId,
          phone_number: smsCodeInfo.phone_number,
          message: smsCodeInfo.message || `请输入手机号${smsCodeInfo.phone_number}收到的短信验证码`,
          timestamp: Date.now(),
        });

        logger.info(`SMS code request sent for account ${accountId}`, {
          requestId,
          phoneNumber: smsCodeInfo.phone_number
        });

        // 监听验证码响应（超时 3 分钟）
        const timeout = setTimeout(() => {
          this.socket.off(`worker:sms_code:response:${requestId}`);
          reject(new Error('SMS code request timeout (3 minutes)'));
        }, 3 * 60 * 1000);

        this.socket.once(`worker:sms_code:response:${requestId}`, (response) => {
          clearTimeout(timeout);

          const smsCode = response.sms_code;
          logger.info(`SMS code received`, {
            requestId,
            accountId,
            codeLength: smsCode ? smsCode.length : 0
          });

          if (!smsCode || smsCode.length === 0) {
            reject(new Error('User cancelled or empty SMS code'));
          } else {
            resolve(smsCode);
          }
        });

      } catch (error) {
        logger.error('Failed to request SMS code:', error);
        reject(error);
      }
    });
  }
```

**说明**:
- 发送 `worker:sms_code:request` 事件到 Master
- 等待 `worker:sms_code:response:{requestId}` 响应
- 超时时间：3分钟
- 空验证码或取消视为失败

```javascript
handleWorkerSMSCodeRequest(socket, data) {
    try {
        logger.info(`[IM WS] 🔔 Worker ${socket.id} SMS code request:`, {
            requestId: data.request_id,
            accountId: data.account_id,
            phoneNumber: data.phone_number
        });

        const smsCodeData = {
            request_id: data.request_id,
            account_id: data.account_id,
            phone_number: data.phone_number,
            message: data.message,
            timestamp: data.timestamp
        };

        // 广播到根命名空间（所有 Monitor 客户端）
        this.io.emit('sms_code:request', smsCodeData);

        // 同时发送到 /client namespace（为未来的新IM客户端准备）
        const clientNamespace = this.io.of('/client');
        clientNamespace.emit('sms_code:request', smsCodeData);

        logger.info(`[IM WS] SMS code request broadcasted to all IM clients, request_id: ${data.request_id}`);

    } catch (error) {
        logger.error('[IM WS] Failed to broadcast SMS code request:', error);
    }
}
```

```typescript
export function showSMSCodeInputDialog(data: {
  request_id: string
  account_id: string
  phone_number: string
  message: string
  timestamp: number
}): void {
  const { request_id, phone_number, message } = data

  let smsCodeInput = ''

  const modal = Modal.confirm({
    title: '📱 输入短信验证码',
    content: (
      <div style={{ marginTop: '16px' }}>
        <div style={{ marginBottom: '12px', lineHeight: '1.6' }}>
          {message}
        </div>
        <div style={{ marginBottom: '8px', fontSize: '13px', color: '#666' }}>
          手机号: {phone_number}
        </div>
        <input
          type="text"
          placeholder="请输入6位验证码"
          maxLength={6}
          style={{
            width: '100%',
            padding: '8px 12px',
            fontSize: '16px',
            border: '1px solid #d9d9d9',
            borderRadius: '4px',
            outline: 'none',
            letterSpacing: '2px'
          }}
          onChange={(e) => {
            smsCodeInput = e.target.value
          }}
          onKeyPress={(e) => {
            if (e.key === 'Enter' && smsCodeInput.length > 0) {
              modal.destroy()
              websocketService.sendSMSCodeResponse(request_id, smsCodeInput)
            }
          }}
          autoFocus
        />
        <div style={{ marginTop: '8px', fontSize: '12px', color: '#999' }}>
          提示: 输入完成后点击「确定」或按回车键
        </div>
      </div>
    ),
    okText: '确定',
    cancelText: '取消',
    width: 450,
    centered: true,
    onOk: () => {
      if (!smsCodeInput || smsCodeInput.length === 0) {
        Modal.warning({
          title: '提示',
          content: '请输入验证码',
          centered: true
        })
        return Promise.reject()
      }
      websocketService.sendSMSCodeResponse(request_id, smsCodeInput)
      return Promise.resolve()
    },
    onCancel: () => {
      websocketService.sendSMSCodeResponse(request_id, '')
    }
  })
}
```

## 错误处理

### 1. 未找到发送验证码按钮

```javascript
return { success: false, message: '未找到发送验证码按钮' }
```

**原因**: 页面结构变化或文本不匹配

**解决**: 更新按钮查找逻辑，添加更多文本匹配

---

### 2. 用户取消输入验证码

```javascript
reject(new Error('User cancelled or empty SMS code'))
```

**原因**: 用户点击「取消」或输入框为空

**Worker处理**: 返回验证失败状态

---

### 3. 未找到验证码输入框

```javascript
return { success: false, message: '未找到验证码输入框' }
```

**原因**: 页面结构变化

**解决**: 提供两种fallback方法（匹配placeholder/name + 使用最后一个input）

---

### 4. 未找到确认按钮

```javascript
return { success: false, message: '未找到确认按钮' }
```

**原因**: 页面结构变化或文本不匹配

**解决**: 支持多种文本（确认/提交/确定/OK）

---

### 5. 验证码错误

```javascript
if (stillHasVerification) {
    return { success: false, message: '验证失败或验证码错误' }
}
```

**检测**: 页面仍包含验证相关文本

**Worker处理**: 返回验证失败状态，不重试
