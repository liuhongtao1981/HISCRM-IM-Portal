# 抖音评论验证检测功能实现

**实现时间**: 2025-12-02
**功能类型**: 🔐 安全验证 - 短信验证码/扫码验证检测与 IM 端交互
**修改文件**:
- `packages/worker/src/platforms/douyin/send-reply-to-comment-video-detail.js`
- `packages/worker/src/platforms/base/worker-bridge.js`
- `packages/worker/src/platforms/douyin/platform.js`

---

## 功能概述

在抖音评论发布过程中，当操作频繁时，平台会触发安全验证机制：
- 📱 **短信验证码验证** - 要求用户输入手机号收到的验证码
- 📷 **扫码验证** - 要求使用原设备扫描二维码

本功能实现了：
1. ✅ 自动检测验证弹窗的出现
2. ✅ 提取验证信息（类型、手机号、提示消息）
3. ✅ 将验证请求发送给 IM 端
4. ✅ 等待用户选择（继续验证 / 取消任务）
5. ✅ 根据用户选择执行相应操作

---

## 验证弹窗触发时机

**验证不是每次都触发**，只有在以下情况才会出现：

1. **频繁操作** - 短时间内发送多条评论
2. **异常行为检测** - 平台检测到可疑操作模式
3. **账号风控** - 账号被标记为需要额外验证

**验证出现时机**：点击"发送"按钮后 1-2 秒内弹出

### 1. 验证检测 (`send-reply-to-comment-video-detail.js`)

#### detectVerification 函数

**位置**: Lines 1145-1228
**作用**: 检测验证弹窗是否出现，并提取验证信息

```javascript
async function detectVerification(page) {
    logger.info('🔍 检测验证弹窗...');

    // 等待 1.5 秒让弹窗出现
    await page.waitForTimeout(1500);

    // 检测验证弹窗
    const verificationInfo = await page.evaluate(() => {
        const bodyText = document.body.textContent || '';

        // 检测短信验证码弹窗
        const hasSMSVerification = bodyText.includes('接收短信验证码') ||
                                  bodyText.includes('为确保是本人操作抖音账号');

        // 检测扫码验证弹窗
        const hasQRVerification = bodyText.includes('使用原设备扫码');

        if (!hasSMSVerification && !hasQRVerification) {
            return { detected: false };
        }

        // 提取手机号（格式：198******35）
        const phoneMatch = bodyText.match(/(\d{3}\*{6}\d{2})/);
        const phoneNumber = phoneMatch ? phoneMatch[1] : '';

        // 提取完整的验证消息
        let message = '';
        const allDivs = Array.from(document.querySelectorAll('div'));
        for (const div of allDivs) {
            const text = div.textContent?.trim() || '';
            if (text.includes('为确保是本人操作抖音账号')) {
                message = text;
                break;
            }
        }

        if (!message && hasSMSVerification) {
            message = phoneNumber
                ? `为确保是本人操作抖音账号，请输入当前手机号${phoneNumber}收到的短信验证码`
                : '为确保是本人操作抖音账号，请输入收到的短信验证码';
        }

        return {
            detected: true,
            type: hasSMSVerification ? 'sms' : 'qrcode',
            phoneNumber,
            message,
            hasSendSMSButton: bodyText.includes('获取验证码') || bodyText.includes('发送验证码'),
            hasQRCodeOption: hasQRVerification
        };
    });

    return verificationInfo;
}
```

**检测逻辑**：
1. 搜索页面文本中的特征关键字
2. 提取手机号（正则匹配 `\d{3}\*{6}\d{2}`）
3. 提取完整验证消息
4. 识别验证类型（SMS / QR Code）
5. 检测可用的验证选项（发送短信按钮 / 扫码选项）

### 2. 验证请求发送 (`worker-bridge.js`)

#### requestVerification 方法

**位置**: Lines 338-405
**作用**: 通过 Socket.IO 将验证请求发送给 Master，并等待 IM 端的响应

```javascript
async requestVerification(accountId, verificationInfo, onUserChoice) {
    if (!this.socket) {
        throw new Error('Socket not connected');
    }

    return new Promise((resolve, reject) => {
        const requestId = `verify_${accountId}_${Date.now()}`;

        // 发送验证请求到 Master
        this.socket.emit('worker:verification:request', {
            request_id: requestId,
            account_id: accountId,
            verification_type: verificationInfo.type,
            message: verificationInfo.message,
            phone_number: verificationInfo.phoneNumber,
            has_sms_button: verificationInfo.hasSendSMSButton,
            has_qrcode_option: verificationInfo.hasQRCodeOption,
            context: {
                aweme_id: verificationInfo.awemeId,
                comment_level: verificationInfo.commentLevel,
                reply_content: verificationInfo.replyContent
            },
            timestamp: Date.now(),
        });

        logger.info(`Verification request sent for account ${accountId}, type: ${verificationInfo.type}`);

        // 监听用户选择响应（超时 5 分钟）
        const timeout = setTimeout(() => {
            this.socket.off(`worker:verification:response:${requestId}`);
            reject(new Error('Verification request timeout (5 minutes)'));
        }, 5 * 60 * 1000);

        this.socket.once(`worker:verification:response:${requestId}`, (response) => {
            clearTimeout(timeout);

            const userChoice = response.choice; // 'yes' | 'no'
            logger.info(`User choice received: ${userChoice}`, {
                requestId,
                accountId,
                choice: userChoice
            });

            if (onUserChoice) {
                onUserChoice(userChoice);
            }

            resolve(userChoice);
        });
    });
}
```

**Socket.IO 消息格式**：

**请求** (`worker:verification:request`):
```json
{
  "request_id": "verify_acc-xxx_1701511234567",
  "account_id": "acc-xxx",
  "verification_type": "sms",
  "message": "为确保是本人操作抖音账号，请输入当前手机号198******35收到的短信验证码",
  "phone_number": "198******35",
  "has_sms_button": true,
  "has_qrcode_option": true,
  "context": {
    "aweme_id": "7533083869034138931",
    "comment_level": 1,
    "reply_content": "你好呀..."
  },
  "timestamp": 1701511234567
}
```

**响应** (`worker:verification:response:{request_id}`):
```json
{
  "choice": "yes"  // or "no"
}
```

**超时机制**: 5 分钟后自动拒绝请求
