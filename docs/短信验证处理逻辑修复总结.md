# 短信验证处理逻辑修复总结

## 修复时间
2025-12-02

## 问题背景

之前的短信验证码处理逻辑存在以下问题：
1. ❌ **步骤1**：返回DOM元素导致序列化后丢失方法，无法点击
2. ❌ **步骤3**：查找 `type="text"` 的输入框，但实际是 `type="number"`
3. ❌ **步骤4**：查找"确认"或"提交"按钮，但实际按钮文本是"验证"
4. ❌ **步骤4**：没有等待按钮从 disabled 变为 enabled 状态

这导致日志显示：
```
❌ 短信验证失败！
💡 失败原因: 未找到发送验证码按钮，可能不是短信验证
```

## 修复方案

### 1. MCP浏览器实时识别验证弹窗元素

使用 MCP Playwright 浏览器打开真实的验证弹窗，识别出准确的元素信息：

#### 识别到的关键元素：

**验证码输入框：**
```html
<input
  maxlength="6"
  pattern="\d*"
  placeholder="请输入验证码"
  type="number"
  value="">
```

**"获取验证码"按钮：**
```html
<p class="uc-ui-typography_description" style="margin-right: 4px; font-weight: normal;">
  获取验证码
</p>
```
- 位于 `.uc-ui-input_right` 容器内
- 标签是 `<p>` 而不是 `<button>`
- Cursor: `pointer`

**"验证"按钮：**
```html
<div class="uc-ui-verify_sms-verify_button primary default uc-ui-button disabled">
  验证
</div>
```
- 初始状态: `disabled` + `cursor: not-allowed`
- 输入验证码后变为: 移除 `disabled` + `cursor: pointer`

### 2. 代码修复详情

#### 修复点1：步骤1 - "获取验证码"按钮点击

**修改前的问题：**
```javascript
const sendSMSButton = await page.evaluate(() => {
    const buttons = Array.from(document.querySelectorAll('button, div[role="button"], span'));
    for (const btn of buttons) {
        const text = btn.textContent?.trim() || '';
        if (text.includes('获取验证码')) {
            return btn;  // ❌ 返回DOM元素，序列化后丢失方法
        }
    }
    return null;
});

// ❌ sendSMSButton 已经是序列化对象，没有 click() 方法
await page.evaluate((btn) => {
    if (btn && typeof btn.click === 'function') {
        btn.click();  // 这里会失败
    }
}, sendSMSButton);
```

**修改后的解决方案：**
```javascript
const sendButtonClicked = await page.evaluate(() => {
    const allElements = Array.from(document.querySelectorAll('p, div, span, button'));

    for (const elem of allElements) {
        // 只获取直接文本节点（避免获取父元素的所有文本）
        let text = '';
        for (const node of elem.childNodes) {
            if (node.nodeType === 3) { // Text node
                text += node.textContent || '';
            }
        }
        text = text.trim();

        // ✅ 精确匹配"获取验证码"
        if (text === '获取验证码' || text === '发送验证码') {
            const rect = elem.getBoundingClientRect();

            // ✅ 确保元素可见且在弹窗内（y坐标在200-500之间）
            if (rect.width > 0 && rect.height > 0 && rect.y > 200 && rect.y < 500) {
                // ✅ 在 evaluate 内部直接点击，使用完整的鼠标事件序列
                const centerX = rect.left + rect.width / 2;
                const centerY = rect.top + rect.height / 2;

                elem.dispatchEvent(new MouseEvent('mousedown', {
                    view: window,
                    bubbles: true,
                    cancelable: true,
                    clientX: centerX,
                    clientY: centerY
                }));

                elem.dispatchEvent(new MouseEvent('click', {
                    view: window,
                    bubbles: true,
                    cancelable: true,
                    clientX: centerX,
                    clientY: centerY
                }));

                elem.dispatchEvent(new MouseEvent('mouseup', {
                    view: window,
                    bubbles: true,
                    cancelable: true,
                    clientX: centerX,
                    clientY: centerY
                }));

                // ✅ 只返回结果对象，不返回DOM元素
                return { success: true, buttonText: text, tagName: elem.tagName };
            }
        }
    }

    return { success: false };
});

if (!sendButtonClicked.success) {
    logger.error('❌ 未找到发送验证码按钮！');
    return { success: false, message: '未找到发送验证码按钮，可能不是短信验证' };
}

logger.info(`✅ 已点击发送验证码按钮 (${sendButtonClicked.tagName}: "${sendButtonClicked.buttonText}")`);
```

**关键改进：**
1. ✅ 在 `page.evaluate()` 内部完成点击操作
2. ✅ 只返回结果对象（`{ success, buttonText, tagName }`），不返回DOM元素
3. ✅ 使用完整的鼠标事件序列（mousedown → click → mouseup）
4. ✅ 精确匹配文本（`===` 而不是 `includes`）
5. ✅ 检查元素可见性和位置（弹窗内）
6. ✅ 查找 `<p>` 标签（不只是 `<button>`）

#### 修复点2：步骤3 - 验证码输入框查找

**修改前的问题：**
```javascript
// ❌ 查找 type="text"，但实际是 type="number"
const inputs = Array.from(document.querySelectorAll('input[type="text"]'));
for (const input of inputs) {
    const placeholder = input.placeholder || '';
    if (placeholder.includes('验证码')) {
        input.value = code;
        // ...
    }
}
```

**修改后的解决方案：**
```javascript
const inputFilled = await page.evaluate((code) => {
    const inputs = Array.from(document.querySelectorAll('input'));

    for (const input of inputs) {
        const placeholder = input.getAttribute('placeholder') || '';
        const type = input.getAttribute('type') || '';
        const maxLength = input.getAttribute('maxlength') || '';
        const rect = input.getBoundingClientRect();

        // ✅ 匹配验证码输入框的特征：
        // - placeholder 包含"验证码"
        // - type="number"（不限制，兼容未来可能的变化）
        // - maxlength="6"
        // - 在弹窗内可见（y坐标在200-500之间）
        if (placeholder.includes('验证码') &&
            rect.width > 0 && rect.height > 0 &&
            rect.y > 200 && rect.y < 500) {

            input.value = code;

            // ✅ 触发所有必要的事件
            input.dispatchEvent(new Event('input', { bubbles: true }));
            input.dispatchEvent(new Event('change', { bubbles: true }));
            input.dispatchEvent(new Event('blur', { bubbles: true }));

            return {
                success: true,
                type: type,
                placeholder: placeholder,
                maxLength: maxLength
            };
        }
    }

    return { success: false };
}, smsCode);

if (!inputFilled.success) {
    logger.error('❌ 未找到验证码输入框');
    return { success: false, message: '未找到验证码输入框' };
}

logger.info(`✅ 验证码已填写 (type="${inputFilled.type}", maxlength="${inputFilled.maxLength}")`);
```

**关键改进：**
1. ✅ 不限制 `type` 属性（兼容 `type="number"` 和 `type="text"`）
2. ✅ 通过 `placeholder` 精确匹配
3. ✅ 检查元素可见性和位置（弹窗内）
4. ✅ 触发 `blur` 事件（某些表单需要）
5. ✅ 返回详细的元素信息用于日志

#### 修复点3：步骤4 - "验证"按钮查找和状态等待

**修改前的问题：**
```javascript
// ❌ 查找"确认"或"提交"，但实际按钮文本是"验证"
const confirmButton = await page.evaluate(() => {
    const buttons = Array.from(document.querySelectorAll('button, div[role="button"]'));
    for (const btn of buttons) {
        const text = btn.textContent?.trim() || '';
        if (text.includes('确认') || text.includes('提交')) {
            return btn;  // ❌ 同样的DOM序列化问题
        }
    }
    return null;
});

// ❌ 没有等待按钮从 disabled 变为 enabled
await page.evaluate((btn) => {
    if (btn && typeof btn.click === 'function') {
        btn.click();  // 可能在 disabled 状态下点击
    }
}, confirmButton);
```

**修改后的解决方案：**
```javascript
// ✅ 主动等待按钮变为可点击状态（最多等待15秒）
let buttonEnabled = false;
for (let i = 0; i < 30; i++) {
    await page.waitForTimeout(500);

    const checkResult = await page.evaluate(() => {
        const buttons = Array.from(document.querySelectorAll('div, button'));

        for (const btn of buttons) {
            // 只获取直接文本节点
            let text = '';
            for (const node of btn.childNodes) {
                if (node.nodeType === 3) {
                    text += node.textContent || '';
                }
            }
            text = text.trim();

            // ✅ 匹配"验证"按钮
            if (text === '验证' || text === '确认' || text === '提交') {
                const rect = btn.getBoundingClientRect();

                // 确保在弹窗内可见
                if (rect.width > 0 && rect.height > 0 && rect.y > 200 && rect.y < 500) {
                    const isDisabled = btn.classList.contains('disabled');
                    const cursor = window.getComputedStyle(btn).cursor;

                    return {
                        found: true,
                        text: text,
                        isDisabled: isDisabled,
                        cursor: cursor,
                        enabled: !isDisabled && cursor === 'pointer'  // ✅ 检查是否可点击
                    };
                }
            }
        }

        return { found: false };
    });

    if (checkResult.found) {
        if (checkResult.enabled) {
            buttonEnabled = true;
            logger.info(`✅ 验证按钮已变为可点击状态 (等待: ${(i + 1) * 500}ms)`);
            break;
        } else if (i === 0) {
            logger.info(`⏳ 验证按钮还是禁用状态，等待变为可点击...`);
        }
    } else if (i === 0) {
        logger.warn('⚠️ 未找到验证按钮');
        break;
    }
}

if (!buttonEnabled) {
    logger.error('❌ 验证按钮未变为可点击状态（超时15秒）');
    return { success: false, message: '验证按钮未变为可点击状态' };
}

// ✅ 点击验证按钮（在 evaluate 内部完成）
const verifyClicked = await page.evaluate(() => {
    const buttons = Array.from(document.querySelectorAll('div, button'));

    for (const btn of buttons) {
        let text = '';
        for (const node of btn.childNodes) {
            if (node.nodeType === 3) {
                text += node.textContent || '';
            }
        }
        text = text.trim();

        if (text === '验证' || text === '确认' || text === '提交') {
            const rect = btn.getBoundingClientRect();

            if (rect.width > 0 && rect.height > 0 && rect.y > 200 && rect.y < 500) {
                const isDisabled = btn.classList.contains('disabled');
                const cursor = window.getComputedStyle(btn).cursor;

                if (!isDisabled && cursor === 'pointer') {
                    btn.click();
                    return { success: true, text: text };
                }
            }
        }
    }

    return { success: false };
});

if (!verifyClicked.success) {
    logger.error('❌ 点击验证按钮失败');
    return { success: false, message: '点击验证按钮失败' };
}

logger.info(`✅ 已点击验证按钮 ("${verifyClicked.text}")`);
```

**关键改进：**
1. ✅ **主动等待机制**：循环检查按钮状态，每500ms检查一次，最多等待15秒
2. ✅ **状态检测**：检查 `classList.contains('disabled')` 和 `cursor` 样式
3. ✅ **精确匹配**："验证"、"确认"、"提交"（按优先级）
4. ✅ **在 evaluate 内部点击**：避免DOM序列化问题
5. ✅ **详细日志**：记录等待时间和按钮状态

## 技术要点总结

### 1. DOM序列化问题的解决

**问题：**
```javascript
// ❌ 错误方式
const element = await page.evaluate(() => {
    return document.querySelector('.button');  // 返回DOM元素
});
await element.click();  // 失败！element 已经被序列化，没有 click() 方法
```

**解决：**
```javascript
// ✅ 正确方式1：在 evaluate 内部完成所有DOM操作
const result = await page.evaluate(() => {
    const element = document.querySelector('.button');
    element.click();  // 在浏览器上下文中点击
    return { success: true };  // 只返回简单对象
});

// ✅ 正确方式2：使用 Playwright 的 locator API
await page.locator('.button').click();
```

### 2. 精确的元素选择策略

**不推荐：**
```javascript
// ❌ 只依赖类名（可能会变化）
document.querySelector('.uc-ui-button')

// ❌ 模糊匹配（可能匹配到错误元素）
text.includes('验证')
```

**推荐：**
```javascript
// ✅ 组合多个特征
placeholder.includes('验证码') &&
rect.width > 0 && rect.height > 0 &&
rect.y > 200 && rect.y < 500

// ✅ 精确匹配文本
text === '获取验证码' || text === '发送验证码'

// ✅ 只获取直接文本节点
let text = '';
for (const node of elem.childNodes) {
    if (node.nodeType === 3) {
        text += node.textContent || '';
    }
}
```

### 3. 主动等待 vs 被动等待

**被动等待（不推荐）：**
```javascript
// ❌ 固定等待时间，可能太长或太短
await page.waitForTimeout(5000);
```

**主动等待（推荐）：**
```javascript
// ✅ 循环检查条件，满足即退出
for (let i = 0; i < 30; i++) {
    await page.waitForTimeout(500);
    const condition = await page.evaluate(() => {
        // 检查条件
        return conditionMet;
    });
    if (condition) {
        break;
    }
}
```

### 4. 事件触发顺序

**最佳实践：**
```javascript
// 完整的鼠标点击事件序列
elem.dispatchEvent(new MouseEvent('mousedown', { ... }));
elem.dispatchEvent(new MouseEvent('click', { ... }));
elem.dispatchEvent(new MouseEvent('mouseup', { ... }));

// 完整的输入事件序列
input.value = value;
input.dispatchEvent(new Event('input', { bubbles: true }));
input.dispatchEvent(new Event('change', { bubbles: true }));
input.dispatchEvent(new Event('blur', { bubbles: true }));
```
