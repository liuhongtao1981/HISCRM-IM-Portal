## 验证弹窗结构

### 1. 验证码输入框

**元素信息：**
```html
<input
  maxlength="6"
  pattern="\d*"
  placeholder="请输入验证码"
  type="number"
  value="">
```

**关键属性：**
- 标签类型: `INPUT`
- 类型: `type="number"`
- 最大长度: `maxlength="6"`
- Pattern: `\d*` (只能输入数字)
- Placeholder: "请输入验证码"
- 父容器类名: `uc-ui-input_textbox`

**位置信息：**
- X: 332.5px
- Y: 339.29px
- 宽度: 179px
- 高度: 18.39px

**推荐选择器：**
```javascript
// 方法1: 通过父容器类名
document.querySelector('.uc-ui-input_textbox input[type="number"]')

// 方法2: 通过 placeholder
document.querySelector('input[placeholder="请输入验证码"]')

// 方法3: 通过 maxlength 和 type
document.querySelector('input[type="number"][maxlength="6"]')
```

**使用建议：**
- 输入验证码时需要使用 `page.fill()` 或 `page.type()`
- 验证码长度固定为 6 位数字
- 可以通过监听 input 值变化来判断用户是否已输入完整验证码

**关键属性：**
- 标签类型: `P` (段落标签)
- 类名: `uc-ui-typography_description`
- 文本内容: "获取验证码"
- 父容器类名: `uc-ui-input_right`
- Cursor: `pointer` (可点击)

**位置信息：**
- X: 562.5px
- Y: 338.5px
- 宽度: 70px
- 高度: 20px

**推荐选择器：**
```javascript
// 方法1: 通过父容器 + 文本内容
const parent = document.querySelector('.uc-ui-input_right');
const button = Array.from(parent.querySelectorAll('p')).find(p =>
  p.textContent.trim() === '获取验证码'
);

// 方法2: 通过类名 + 文本内容
const buttons = Array.from(document.querySelectorAll('.uc-ui-typography_description'));
const sendButton = buttons.find(btn => btn.textContent.trim() === '获取验证码');

// 方法3: 直接遍历查找（最可靠）
const allElements = Array.from(document.querySelectorAll('p, div, span'));
const sendCodeBtn = allElements.find(elem => {
    const text = elem.textContent?.trim() || '';
    const rect = elem.getBoundingClientRect();
    return text === '获取验证码' && rect.width > 0 && rect.height > 0;
});
```

**点击方式：**
```javascript
// 方式1: 使用完整鼠标事件序列
const rect = button.getBoundingClientRect();
button.dispatchEvent(new MouseEvent('mousedown', {
    view: window,
    bubbles: true,
    cancelable: true,
    clientX: rect.left + rect.width / 2,
    clientY: rect.top + rect.height / 2
}));

button.dispatchEvent(new MouseEvent('click', {
    view: window,
    bubbles: true,
    cancelable: true,
    clientX: rect.left + rect.width / 2,
    clientY: rect.top + rect.height / 2
}));

button.dispatchEvent(new MouseEvent('mouseup', {
    view: window,
    bubbles: true,
    cancelable: true,
    clientX: rect.left + rect.width / 2,
    clientY: rect.top + rect.height / 2
}));

// 方式2: 直接点击
button.click();
```

**注意事项：**
- 这是一个 `<p>` 标签而非 `<button>`，需要使用鼠标事件模拟点击
- 点击后验证码会发送到手机号 198******35
- 点击后文本可能会变为"重新发送"或显示倒计时

## 完整的验证流程代码示例

### 步骤1: 点击"获取验证码"

```javascript
// 在 page.evaluate() 中执行
const sendCodeButton = await page.evaluate(() => {
    const allElements = Array.from(document.querySelectorAll('p, div, span'));

    for (const elem of allElements) {
        const text = elem.textContent?.trim() || '';
        const rect = elem.getBoundingClientRect();

        if (text === '获取验证码' && rect.width > 0 && rect.height > 0) {
            // 使用完整鼠标事件序列点击
            const centerX = rect.left + rect.width / 2;
            const centerY = rect.top + rect.height / 2;

            elem.dispatchEvent(new MouseEvent('mousedown', {
                view: window,
                bubbles: true,
                cancelable: true,
                clientX: centerX,
                clientY: centerY
            }));

            elem.dispatchEvent(new MouseEvent('click', {
                view: window,
                bubbles: true,
                cancelable: true,
                clientX: centerX,
                clientY: centerY
            }));

            elem.dispatchEvent(new MouseEvent('mouseup', {
                view: window,
                bubbles: true,
                cancelable: true,
                clientX: centerX,
                clientY: centerY
            }));

            return true;
        }
    }

    return false;
});

if (sendCodeButton) {
    logger.info('✅ 已点击"获取验证码"按钮');
} else {
    logger.error('❌ 未找到"获取验证码"按钮');
}
```

### 步骤2: 等待用户输入验证码

```javascript
// 提示用户输入验证码
logger.info('请在手机上查看验证码，并在30秒内输入...');

// 等待验证码输入（最多30秒）
const codeEntered = await page.waitForFunction(() => {

    return input && input.value.length === 6;
}, { timeout: 30000 }).catch(() => false);

if (!codeEntered) {
    logger.error('❌ 验证码输入超时');
    return;
}
```

### 步骤3: 点击"验证"按钮

```javascript
// 等待验证按钮变为可点击状态
const buttonEnabled = await page.evaluate(async () => {
    for (let i = 0; i < 10; i++) {
        const btn = document.querySelector('.uc-ui-verify_sms-verify_button.primary');
        if (!btn) return false;

        const isDisabled = btn.classList.contains('disabled');

    const btn = document.querySelector('.uc-ui-verify_sms-verify_button.primary');
    if (!btn) return false;

    btn.click();
    return true;
});

if (verified) {
    logger.info('✅ 已点击"验证"按钮');
} else {
    logger.error('❌ 点击"验证"按钮失败');
}
```

## 关键发现和建议

### 1. 元素选择策略

**最可靠的方法：**
- 使用文本内容 + 可见性检查（`getBoundingClientRect()`）
- 避免只依赖类名，因为类名可能会变化
- 优先使用 `placeholder`、`type`、`maxlength` 等稳定属性

### 2. 点击方式

**"获取验证码"按钮：**
- 建议使用完整的鼠标事件序列（mousedown → click → mouseup）
- 计算元素中心点坐标进行点击
- 这是一个 `<p>` 标签，简单的 `click()` 可能不起作用

**"验证"按钮：**
- 可以直接使用 `click()` 方法
- 必须等待按钮从 disabled 状态变为 enabled
- 监听 `classList` 和 `cursor` 样式变化

### 3. 状态检测

**输入框状态：**
```javascript
const input = document.querySelector('input[placeholder="请输入验证码"]');
const isComplete = input && input.value.length === 6;
```

**按钮状态：**
```javascript
const button = document.querySelector('.uc-ui-verify_sms-verify_button.primary');
const isEnabled = button &&
                  !button.classList.contains('disabled') &&
                  window.getComputedStyle(button).cursor === 'pointer';
```

### 4. 等待策略

**主动等待（Active Waiting）：**
```javascript
// 推荐：每500ms检查一次，最多等待N秒
for (let i = 0; i < maxAttempts; i++) {
    if (conditionMet()) {
        return true;
    }
    await new Promise(resolve => setTimeout(resolve, 500));
}
```

**被动等待（Passive Waiting）：**
```javascript
// 不推荐：固定等待时间
await page.waitForTimeout(3000);
```

### 5. 错误处理

**常见错误场景：**
1. 验证码输入错误
2. 验证码过期（通常60秒）
3. 网络问题导致验证失败
4. 用户取消验证

**建议：**
- 每个步骤都要有超时机制
- 捕获所有可能的错误提示
- 截图保存错误状态以便调试
