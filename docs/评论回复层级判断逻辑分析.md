## 问题根源分析

### 错误的判断依据

当前逻辑使用 **`target_comment` 的 `reply_id` 和 `reply_to_reply_id` 字段** 来判断要发送的回复层级。

**这是错误的！**

**正确的理解**:
- `target_comment` 是**被回复的评论**的数据
- `target_comment.reply_id` 表示**被回复的评论**是几级评论
- 我们要发送的回复层级 = **被回复的评论**的层级 + 1

### 正确的判断逻辑

| 被回复的评论 | 被回复评论的字段 | 我们要发送的回复 | 应该判断为 |
|------------|----------------|---------------|----------|
| 一级评论 | `reply_id='0'`, `reply_to_reply_id='0'` | 回复一级评论 | **二级回复** |
| 二级评论 | `reply_id=一级ID`, `reply_to_reply_id='0'` | 回复二级评论 | **三级回复** |
| 三级评论 | `reply_id=一级ID`, `reply_to_reply_id=二级ID` | ⚠️ 抖音不支持四级 | **三级回复** (挂在同一个二级下) |

## 修复方案

### 方案 1: 基于 target_comment 的层级判断 ⭐ 推荐

**逻辑**:
1. 如果没有 `target_id` → 一级评论
2. 如果有 `target_id` 但没有 `target_comment` → 默认二级回复
3. 如果有 `target_comment`:
   - 判断 `target_comment` 是几级评论
   - 要发送的回复 = `target_comment` 的层级 + 1 (最多3级)

**代码**:
```javascript
// 确定评论层级和相关ID
let commentLevel = 1;
let replyId = null;
let replyToReplyId = null;

if (!target_id) {
    // 场景1: 没有回复目标 → 一级评论
    commentLevel = 1;
} else if (!target_comment) {
    // 场景2: 有 target_id 但没有详细数据 → 默认二级回复
    commentLevel = 2;
    replyId = target_id;
} else {
    // 场景3: 有完整的 target_comment 数据
    // 判断 target_comment 是几级评论
    const targetCommentLevel = getCommentLevel(target_comment);

    if (targetCommentLevel === 1) {
        // 回复一级评论 → 发送二级回复
        commentLevel = 2;
        replyId = target_id;  // 一级评论ID
        replyToReplyId = null;
    } else if (targetCommentLevel === 2) {
        // 回复二级评论 → 发送三级回复
        commentLevel = 3;
        replyId = target_comment.reply_id;  // 一级根评论ID
        replyToReplyId = target_id;  // 二级评论ID
    } else {
        // 回复三级评论 → 仍然发送三级回复（抖音不支持四级）
        commentLevel = 3;
        replyId = target_comment.reply_id;  // 一级根评论ID
        replyToReplyId = target_comment.reply_to_reply_id;  // 二级评论ID
    }
}

/**
 * 辅助函数：判断评论是几级
 */
function getCommentLevel(comment) {
    if (!comment.reply_id || comment.reply_id === '0') {
        return 1;  // 一级评论
    }
    if (!comment.reply_to_reply_id || comment.reply_to_reply_id === '0') {
        return 2;  // 二级评论
    }
    return 3;  // 三级评论
}
```

### 方案 2: 简化版（假设 Master 不会发送三级评论的回复请求）

如果我们假设 Master 只会发送：
- 一级评论请求（target_id = null）
- 二级回复请求（target_comment 是一级评论）
- 三级回复请求（target_comment 是二级评论）

**代码**:
```javascript
let commentLevel = 1;
let replyId = null;
let replyToReplyId = null;

if (!target_id) {
    // 一级评论
    commentLevel = 1;
} else if (!target_comment) {
    // 有 target_id 但没有详细数据，默认二级
    commentLevel = 2;
    replyId = target_id;
} else {
    // 检查 target_comment 是否是一级评论（reply_id 和 reply_to_reply_id 都是 '0'）
    const isFirstLevelComment = (!target_comment.reply_id || target_comment.reply_id === '0');

    if (isFirstLevelComment) {
        // 回复一级评论 → 二级回复
        commentLevel = 2;
        replyId = target_id;
    } else {
        // 回复二级或三级评论 → 三级回复
        commentLevel = 3;
        replyId = target_comment.reply_id;  // 一级根评论
        replyToReplyId = target_id;  // 被回复的评论（二级或三级）
    }
}
```
