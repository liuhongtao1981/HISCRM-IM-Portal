# 二级评论回复失败问题诊断

## 问题现象
用户尝试回复评论"苏苏 回复 你好"时，回复没有发送成功。

## 日志分析

### 1. 评论数据（数据库）
- **评论ID**: 7578702518957261568
- **作者**: 苏苏 (用户ID: 106228603660, sec_uid: MS4wLjABAAAAhQl-Xyl8opYFwpzFnm93Zt9Rp9H-1C40VCZ4y5YLnDk)
- **内容**: "你好"
- **层级**: 1（**一级评论**）
- **视频ID**: 7533516758959820070
- **视频标题**: "临终关怀费用大揭秘，到底贵不贵呢..."

### 2. 回复流程日志
```
[09:58:16.003] IM WS 添加到发送队列: reply_1764554296003_h74cizjcd
[09:58:16.005] IM WS 找到评论: "你好..." (ID: 7578702518957261568)

```

## 问题根本原因

### Worker 返回的错误：`未找到评论 7578702518957261568`

尽管数据库中有这条评论的记录，但 **Worker 在抖音创作中心页面找不到它**。

### 可能的原因

#### 1. 评论ID格式不匹配（最可能）
抖音最近将评论ID从数字格式（如 `7578702518957261568`）改为加密格式（如 `@i/Fs6L9ITkf8t...`）。

查看代码 [send-reply-to-comment.js:965-978](../packages/worker/src/platforms/douyin/send-reply-to-comment.js#L965-L978)：
```javascript
// 判断是否像评论ID
function isLikeCommentId(val) {
    const str = String(val);
    // 数字格式（10位以上）
    if (/^\d{10,}$/.test(str)) return true;
    // 加密格式（@i/ 开头）
    if (str.startsWith('@i/') && str.length > 10) return true;
    return false;
}
```

虽然代码支持两种格式，但在 React Fiber 匹配时可能出现问题：
- **数据库存储的是数字ID**：`7578702518957261568`
- **页面上的 cid 可能是加密ID**：`@i/xxx`

#### 2. 评论不在当前视口（虚拟列表问题）
抖音创作中心使用虚拟列表，评论可能需要滚动才能加载到 DOM 中。

代码中有滚动查找逻辑 [send-reply-to-comment.js:485-634](../packages/worker/src/platforms/douyin/send-reply-to-comment.js#L485-L634)：
- 最多滚动 50 次
- 每次滚动 500px
- 连续 3 次没有新内容则停止

但是如果评论在很后面，可能滚动次数不够。

#### 3. 匹配策略问题
代码使用三种匹配策略：
1. **内容+昵称匹配**（优先，代码 718-919 行）
2. **ID 匹配（data-attrs）**（代码 924-946 行）
3. **ID 匹配（React Fiber）**（代码 951-1079 行）

如果页面上的评论数据结构发生变化，可能导致所有匹配失败。

#### 4. 一级评论 vs 二级评论混淆
用户描述是"苏苏 回复 你好"，听起来像是二级评论回复。
但数据显示这是**一级评论**（level: 1, parentCommentId: null）。

可能的情况：
- 用户想要**回复**"苏苏"的一级评论"你好"（创建二级回复）
- 但系统尝试**修改或重新发送**一级评论"你好"
