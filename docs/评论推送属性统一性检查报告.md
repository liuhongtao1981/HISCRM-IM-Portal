## 一、数据流转链路

### 完整链路

```
抖音API响应（蛇形）
    ↓
Worker normalizeComment（标准化为蛇形）
    ↓
Worker mapCommentData（映射为驼峰）
    ↓
DataStore（统一驼峰格式）
    ↓
Master im-websocket-server（推送驼峰格式）
    ↓
Frontend MonitorPage（接收驼峰格式）
```

## 三、修复对比

### 修复前（存在混乱）

#### Worker data-manager.js
```javascript
// ❌ 缺少关键字段映射
return {
  commentId: String(douyinData.cid),
  parentCommentId: douyinData.parent_comment_id ? String(...) : null,
  // ❌ 缺少 replyId
  // ❌ 缺少 replyToReplyId
  replyToUserName: douyinData.reply_to_username,  // ❌ 命名不一致（UserName）
};
```

#### Master im-websocket-server.js
```javascript
// ❌ 混用蛇形和驼峰 fallback
const replyId = comment.replyId || comment.reply_id;  // ❌ 有蛇形 fallback
const parentId = comment.parentCommentId || comment.parent_comment_id;  // ❌ 有蛇形 fallback
replyToUsername: comment.replyToUsername || comment.reply_to_username || null,  // ❌ 有蛇形 fallback
```

**问题**：
- DataStore 缺少 `replyId` 字段 → `comment.replyId` 为 `undefined`
- 所有评论回退到 `parentCommentId`（树形结构） → 三级评论无法显示
- 字段命名不一致（`replyToUserName` vs `replyToUsername`）

---

### 修复后（已统一）

#### Worker data-manager.js (Line 331-335)
```javascript
// ✅ 完整映射，统一命名
return {
  commentId: String(douyinData.cid),
  parentCommentId: douyinData.parent_comment_id ? String(...) : null,
  replyId: douyinData.reply_id ? String(douyinData.reply_id) : null,  // ✅ 新增
  replyToReplyId: douyinData.reply_to_reply_id ? String(...) : null,  // ✅ 新增
  replyToUsername: douyinData.reply_to_username || null,  // ✅ 统一命名（Username）
};
```

#### Master im-websocket-server.js (Line 1115-1141)
```javascript
// ✅ 移除蛇形 fallback，统一使用驼峰
const replyId = comment.replyId;  // ✅ 仅驼峰
const parentId = comment.parentCommentId;  // ✅ 仅驼峰
replyToUsername: comment.replyToUsername || null,  // ✅ 仅驼峰
```

**效果**：
- ✅ DataStore 包含 `replyId` 字段
- ✅ `comment.replyId` 正确读取（扁平化显示）
- ✅ 三级评论正确显示在一级评论下方
- ✅ 字段命名完全统一（camelCase）

## 五、字段命名规范

### 统一规则

1. **全局统一使用 camelCase**
   - ✅ `commentId`, `authorName`, `replyToId`
   - ❌ `comment_id`, `author_name`, `reply_to_id`

2. **复合词命名**
   - ✅ `replyToUsername`（To 首字母大写，Username 作为单词）
   - ❌ `replyToUserName`（UserName 大驼峰）
   - ❌ `reply_to_username`（蛇形）

3. **布尔值命名**
   - ✅ `isAuthorReply`, `isRead`, `isPinned`
   - ❌ `is_author_reply`, `is_read`, `is_pinned`

4. **时间戳命名**
   - ✅ `createdAt`, `updatedAt`, `detectedAt`
   - ❌ `created_at`, `updated_at`, `detected_at`

### 特殊字段对照

| API 蛇形字段 | DataStore 驼峰字段 | 说明 |
|-------------|-------------------|------|
| `reply_id` | `replyId` | 一级评论ID |
| `reply_to_reply_id` | `replyToReplyId` | 三级评论的二级父评论ID |
| `reply_to_username` | `replyToUsername` | 回复的用户名 |
| `reply_to_userid` | `replyToUserId` | 回复的用户ID |
| `parent_comment_id` | `parentCommentId` | 直接父评论ID |
| `is_author` | `isAuthorReply` | 是否作者回复 |
| `create_time` | `createdAt` | 创建时间 |
| `user_info` | `userInfo` 或展开 | 用户信息 |
