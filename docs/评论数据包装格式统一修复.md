## 最严重的问题：`is_author` 缺失

### 问题影响

**crawler-api.js 爬取的评论没有 `is_author` 字段**，导致：

1. ❌ `mapCommentData` 中 `direction` 判断错误
2. ❌ 所有评论的 `direction` 都是 `undefined`（因为 `is_author` 缺失）
3. ❌ `direction` 为 `undefined` 时，默认值是 `'inbound'`
4. ❌ **我们自己发的评论也被标记为 `inbound`**（别人发的）
5. ❌ 无法区分评论的真实方向

### `is_author` 判断逻辑

**问题根源**：API 返回的评论数据中**没有** `is_author` 字段！

**正确的判断方法**：
```javascript
// 对比评论作者的 uid 和账户的 platform_user_id
const is_author = comment.user.uid === account.platform_user_id
```

### Account 模型中的 platform_user_id

## 修复方案

### 1. crawler-api.js - saveComments 方法

**位置**: `packages/worker/src/platforms/douyin/crawler-api.js:484-512`

**修复前**:
```javascript
const normalizedComments = comments.map(comment => ({
    comment_id: String(comment.cid),
    cid: String(comment.cid),
    aweme_id: workId,
    text: comment.text,
    create_time: comment.create_time,
    digg_count: comment.digg_count || 0,
    reply_count: comment.reply_comment_total || 0,
    user_info: {
        user_id: comment.user.uid,
        uid: comment.user.uid,
        nickname: comment.user.nickname,
        avatar_url: comment.user.avatar_thumb?.url_list?.[0] || null,
    },
    user: comment.user,
    _raw: comment,
    _api_version: 'v2',
    // ❌ 缺少 is_author、is_pinned、user_digged 等字段
}));
```

**修复后**:
```javascript
// ✅ 获取账户的用户 ID，用于判断评论是否是我们自己发的
const accountUserId = this.account.platform_user_id;

const normalizedComments = comments.map(comment => ({
    comment_id: String(comment.cid),
    cid: String(comment.cid),
    aweme_id: workId,
    item_id: workId,  // ✅ 新增
    text: comment.text,
    content: comment.text,  // ✅ 新增
    create_time: comment.create_time,
    digg_count: comment.digg_count || 0,
    reply_count: comment.reply_comment_total || 0,
    user_info: {
        user_id: comment.user.uid,
        uid: comment.user.uid,
        nickname: comment.user.nickname,
        avatar_url: comment.user.avatar_thumb?.url_list?.[0] || null,
    },
    user: comment.user,
    // ✅ 核心修复：添加 is_author 字段
    // 通过对比评论作者 uid 和账户 platform_user_id 判断
    is_author: accountUserId && String(comment.user.uid) === String(accountUserId),
    is_pinned: comment.is_pinned || false,  // ✅ 新增
    user_digged: comment.user_digged || 0,  // ✅ 新增
    _raw: comment,
    _api_version: 'v2',
}));
```

**新增字段说明**：
- `item_id`: 作品 ID（与 aweme_id 相同，保持兼容性）
- `content`: 评论内容（与 text 相同，保持兼容性）
- **`is_author`**: 判断是否是我们自己发的评论（核心修复）
  - 对比 `comment.user.uid` 和 `account.platform_user_id`
  - `true` → 我们自己发的评论 → `direction = 'outbound'`
  - `false` → 别人发的评论 → `direction = 'inbound'`
- `is_pinned`: 是否置顶（默认 false）
- `user_digged`: 是否点赞（默认 0）
