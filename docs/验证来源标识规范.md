# 验证来源标识规范

**文档类型**: 📋 规范文档 - 验证来源 (source) 和平台标识 (platform) 定义
**创建时间**: 2025-12-02
**适用范围**: Worker-Master-IM 端验证功能

---

## 概述

为了支持未来多平台、多场景的验证扩展，在验证请求消息中添加了两个标识字段：
- **`source`**: 验证来源，标识触发验证的具体操作场景
- **`platform`**: 平台标识，标识验证所属的社交媒体平台

---

## 验证来源 (source) 规范

### 命名格式

```
{platform}_{operation}_{detail}
```

**字段说明**:
- `platform`: 平台简称（如 `douyin`, `xiaohongshu`, `weibo`）
- `operation`: 操作类型（如 `comment`, `dm`, `login`, `post`）
- `detail`: 具体细节（可选，如 `reply`, `send`, `publish`）

## IM 端使用建议

### 根据来源显示不同 UI

```javascript
socket.on('verification:request', (data) => {
  const { source, platform, message } = data;

  // 根据来源自定义标题
  const title = getVerificationTitle(source);

  // 根据平台自定义图标
  const icon = getPlatformIcon(platform);

  showVerificationDialog({
    title,
    icon,
    message,
    source,
    platform,
    ...data
  });
});

function getVerificationTitle(source) {
  const titles = {
    'douyin_comment_reply': '抖音评论验证',
    'douyin_dm_send': '抖音私信验证',
    'douyin_login': '抖音登录验证',
    'xiaohongshu_comment_reply': '小红书评论验证',
    'xiaohongshu_note_publish': '小红书发布验证',
    // ...更多
  };

  return titles[source] || '验证提示';
}

function getPlatformIcon(platform) {
  const icons = {
    'douyin': '🎵',
    'xiaohongshu': '📕',
    'weibo': '📰',
    'wechat': '💬',
    // ...更多
  };

  return icons[platform] || '⚠️';
}
```

### 根据来源记录统计

```javascript
socket.on('verification:request', (data) => {
  const { source, platform } = data;

  // 记录验证统计
  recordVerificationStats({
    source,
    platform,
    timestamp: Date.now()
  });

  // 显示弹窗
  showVerificationDialog(data);
});
```

## 验证来源的使用场景

### 1. 日志记录

**Worker 端**:
```
Verification request sent for account acc-xxx, source: douyin_comment_reply, platform: douyin, type: sms
```

**Master 端**:
```
Worker {socket_id} verification request: { requestId, accountId, source: 'douyin_comment_reply', platform: 'douyin', ... }
Verification request forwarded to IM client, request_id: verify_acc-xxx_xxx, source: douyin_comment_reply, platform: douyin
```

---

### 2. 统计分析

IM 端可以统计不同来源的验证频率：

```javascript
const verificationStats = {
  'douyin_comment_reply': 15,  // 抖音评论验证触发 15 次
  'douyin_dm_send': 3,         // 抖音私信验证触发 3 次
  'xiaohongshu_comment_reply': 8,
  // ...
};
```

---

### 3. 用户体验优化

根据不同来源显示不同的提示信息：

```javascript
const tips = {
  'douyin_comment_reply': '频繁评论可能触发验证，建议适当降低评论频率',
  'douyin_dm_send': '批量发送私信可能触发验证，建议分批发送',
  'douyin_login': '登录验证是正常的安全措施，请完成验证',
};

const tip = tips[source] || '请完成验证以继续操作';
```

---

### 4. 验证策略优化

Worker 端可以根据不同来源实施不同的验证策略：

```javascript
// 评论回复验证：支持短信验证码和扫码
if (source === 'douyin_comment_reply') {
  // 提供短信验证码输入选项
  // 提供扫码验证选项
}

// 登录验证：只支持扫码
if (source === 'douyin_login') {
  // 只提供扫码验证选项
}
```

## 兼容性

### 向后兼容

如果旧版本的 Worker 未提供 `source` 或 `platform` 字段，系统会使用默认值 `'unknown'`：

```javascript
source: verificationInfo.source || 'unknown',
platform: verificationInfo.platform || 'unknown',
```

### IM 端兼容

IM 端应检查这两个字段是否存在：

```javascript
socket.on('verification:request', (data) => {
  const source = data.source || 'unknown';
  const platform = data.platform || 'unknown';

  // 使用默认处理逻辑
  if (source === 'unknown') {
    console.warn('Unknown verification source, using default UI');
  }

  // 显示弹窗
  showVerificationDialog(data);
});
```

## 最佳实践

### 1. 始终指定明确的来源

❌ **错误示例**:
```javascript
verificationInfo = {
  source: 'unknown',  // 不应使用 unknown
  platform: 'unknown',
  // ...
};
```

✅ **正确示例**:
```javascript
verificationInfo = {
  source: 'douyin_comment_reply',  // 明确的来源
  platform: 'douyin',              // 明确的平台
  // ...
};
```

---

### 2. 使用一致的命名格式

❌ **错误示例**:
```javascript
source: 'douyinCommentReply',  // 驼峰命名
source: 'Douyin-Comment-Reply',  // 短横线命名
source: 'douyin.comment.reply',  // 点分隔
```

✅ **正确示例**:
```javascript
source: 'douyin_comment_reply',  // 下划线命名（统一规范）
```

---

### 3. 在日志中记录来源

所有与验证相关的日志都应包含 `source` 和 `platform` 信息：

```javascript
logger.info('Verification detected', {
  source: 'douyin_comment_reply',
  platform: 'douyin',
  accountId,
  verificationType
});
```
