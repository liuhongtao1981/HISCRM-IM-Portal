## 优化建议

### 建议1：增加更细致的错误判断

```javascript
// 检查验证结果（增强版）
logger.info('📍 [步骤5] 检查验证结果...');

const verificationResult = await page.evaluate(() => {
    const bodyText = document.body.textContent || '';

    // 检查各种可能的文本
    const hasVerificationPopup =
        bodyText.includes('接收短信验证码') ||
        bodyText.includes('为确保是本人操作抖音账号');

    const hasErrorMessage =
        bodyText.includes('验证码错误') ||
        bodyText.includes('验证码有误') ||
        bodyText.includes('验证失败');

    const hasExpiredMessage =
        bodyText.includes('验证码已过期') ||
        bodyText.includes('验证码失效');

    return {
        hasPopup: hasVerificationPopup,
        hasError: hasErrorMessage,
        hasExpired: hasExpiredMessage,
        bodyPreview: bodyText.substring(0, 200)  // 前200字符用于调试
    };
});

// 根据详细结果判断
if (verificationResult.hasError) {
    logger.error('❌ 验证码错误');
    return { success: false, message: '验证码错误，请重新输入' };
}

if (verificationResult.hasExpired) {
    logger.error('❌ 验证码已过期');
    return { success: false, message: '验证码已过期，请重新获取' };
}

if (verificationResult.hasPopup) {
    logger.warn('⚠️ 验证弹窗仍然存在（原因未知）');
    return { success: false, message: '验证失败，弹窗未关闭' };
}

logger.info('✅ 短信验证成功！');
return { success: true };
```

## 推荐实现

结合上述建议，推荐使用以下判断逻辑：

```javascript
// 5. 检查验证是否成功
logger.info('📍 [步骤5] 检查验证结果...');

// 主动等待弹窗消失（最多10秒）
let verified = false;
let errorMessage = '';

for (let i = 0; i < 20; i++) {
    await page.waitForTimeout(500);

    const checkResult = await page.evaluate(() => {
        const bodyText = document.body.textContent || '';

        // 检查错误消息
        if (bodyText.includes('验证码错误') || bodyText.includes('验证码有误')) {
            return { status: 'error', message: '验证码错误' };
        }

        if (bodyText.includes('验证码已过期') || bodyText.includes('验证码失效')) {
            return { status: 'error', message: '验证码已过期' };
        }

        // 检查弹窗是否还存在
        const hasPopup =
            bodyText.includes('接收短信验证码') ||
            bodyText.includes('为确保是本人操作抖音账号');

        if (hasPopup) {
            return { status: 'waiting', message: '弹窗仍存在' };
        }

        // 弹窗已消失
        return { status: 'success', message: '验证成功' };
    });

    if (checkResult.status === 'error') {
        // 发现错误，立即返回
        logger.error(`❌ ${checkResult.message}`);
        return { success: false, message: checkResult.message };
    }

    if (checkResult.status === 'success') {
        // 验证成功
        verified = true;
        logger.info(`✅ 验证弹窗已消失（等待: ${(i + 1) * 500}ms）`);
        break;
    }

    // status === 'waiting'，继续等待
    if (i === 0) {
        logger.info('⏳ 等待验证弹窗消失...');
    }
}

if (!verified) {
    logger.error('❌ 验证弹窗未在10秒内消失（超时）');
    return { success: false, message: '验证超时，弹窗未关闭' };
}

logger.info('✅ 短信验证成功！');
return { success: true };
```

**优点：**
1. ✅ 主动等待弹窗消失（不是固定等待3秒）
2. ✅ 检测详细的错误消息
3. ✅ 区分不同的失败原因
4. ✅ 最快500ms就能判断成功，最慢10秒超时
5. ✅ 日志更详细，便于调试

## 总结

### 当前方法（简单但有效）
- **原理：** 等待3秒 → 检查文本 → 判断
- **优点：** 简单、快速
- **缺点：**
  - 固定等待3秒（可能太长或太短）
  - 不区分错误类型
  - 没有超时保护

### 推荐方法（更可靠）
- **原理：** 主动等待 → 检查详细状态 → 区分错误 → 判断
- **优点：**
  - 响应更快（成功时可能只需500ms）
  - 错误信息更详细
  - 有超时保护
- **缺点：**
  - 代码稍复杂
